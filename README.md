# S.P.L.I.T. — русская локализация

Неофициальный русский перевод Steam-версии **S.P.L.I.T.** от Mike Klubnika.

Репозиторий не содержит игру, оригинальные ресурсы или полный `PCK`. В нём лежат только перевод, проверяемые текстовые изменения и установщик. Пользователь должен владеть игрой в Steam.

## Установка

1. На странице репозитория нажмите **Code → Download ZIP**.
2. Полностью распакуйте архив.
3. Закройте игру.
4. Запустите `install_ru.bat`.
5. После завершения запускайте S.P.L.I.T. обычной кнопкой **«Играть»** в Steam.

При первой установке скрипт автоматически скачает официальный выпуск [Godot RE Tools](https://github.com/GDRETools/gdsdecomp), восстановит только необходимые ресурсы, применит перевод, скомпилирует их под Godot 4.4.1 и соберёт новый Steam EXE.

Установщик создаёт резервную копию рядом с игрой:

```text
split.exe.split_ru_backup
```

## Удаление

Запустите `uninstall_ru.bat`. Оригинальный `split.exe` будет восстановлен из резервной копии.

Также русификатор можно убрать через Steam: **Свойства → Установленные файлы → Проверить целостность файлов**. После этого резервную копию `*.split_ru_backup` можно удалить вручную.

## Поддерживаемая версия

Текущая тестовая сборка рассчитана на Steam EXE с SHA-256:

```text
2F5E7E3EC06E1E3ECA3623E75DF65DE342DC39E21B886B59BA5D455BC752C9F6
```

При обновлении игры установщик остановится до изменения файлов и покажет новую контрольную сумму. Это защищает игру от применения патча к несовместимой версии.

## Что переведено

- сюжетный IRC-чат;
- меню и настройки;
- терминал и программы;
- документы и сообщения;
- субтитры, мысли и экран смерти;
- титры и интерфейсные подсказки.

Команды, пути, IP-адреса, логины, пароли и служебные имена файлов оставлены без изменений, чтобы не ломать прохождение.

## Техническая схема

`translation_patch.json` содержит небольшие проверяемые изменения исходных текстовых ресурсов. Установщик:

1. находит S.P.L.I.T. в библиотеках Steam;
2. проверяет SHA-256 оригинального EXE;
3. создаёт резервную копию;
4. восстанавливает изменяемые GDScript и сцены через GDRETools;
5. проверяет SHA-256 каждого исходного ресурса;
6. применяет перевод и снова проверяет контрольные суммы;
7. компилирует GDScript и бинарные сцены;
8. заменяет только изменённые записи в PCK;
9. встраивает PCK обратно в родной Steam EXE.

Steam-интеграция и достижения остаются из оригинального исполняемого файла.

## Статус

Это первая Steam-сборка для тестирования. Перед установкой рекомендуется убедиться, что Steam Cloud синхронизировал сохранения. О найденных ошибках перевода или установки сообщайте через Issues.

## Правовая информация

S.P.L.I.T., оригинальные тексты и игровые ресурсы принадлежат их правообладателям. Проект не связан с Mike Klubnika и не распространяет копию игры.
